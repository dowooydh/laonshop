# 간격·사이즈·카탈로그 후속 독립 QA 수용 조건

기준일: 2026-11-04. 실행 결과와 제품 SHA는 최종 보고서에서 확정합니다.

- 화면 인벤토리: 홈, 남성/여성 목록, 검색/빈 검색, 상품상세(의류·신발·잡화), 장바구니(비어 있음/상품 있음), 고객센터, 정책 4종, 로그인/가입, 구매자 체크아웃·마이·설정·주문·내역서, 관리자 센터·배송관리·내역서를 포함합니다.
- 320/390/768/1280px × 100/200%에서 문서 가로넘침, 필드/버튼 잘림, 인접 명령 겹침, dt/dd 텍스트 수직 정렬을 검사합니다. 200%는 root font-size 32px로 동일하게 재현합니다.
- 공통 Button의 primary/danger와 입력·라벨·Amount·Card 등은 실제 계산 색상과 대비를 확인합니다. 커스텀 text-step 크기가 텍스트 색상을 지우지 않아야 합니다.
- 상품상세의 배송비/출고/교환·반품 행은 실제 글자의 수직 중심이 일치해야 하고 링크 44px 클릭 영역은 유지합니다. 다중 행은 자연스럽게 줄바꿈되어야 합니다.
- 사이즈표는 현재 상품 옵션·분류·성별과 일치하고 참고용 정보임을 식별할 수 있어야 합니다. 실제 실측치로 오해시키지 않으며 신발/가방/기타 잡화에는 적절한 안내를 표시합니다.
- 예시 후기는 미리보기에서만 표시하고 예시임이 명확해야 합니다. 상품당 최소 30개 평가, 10% 이상 텍스트 구성 조건을 검사하며 실제 구매후기 집계·실구매 원장에는 추가하지 않습니다. Production에서는 예시 후기와 집계가 나타나지 않아야 합니다.
- 카테고리/상품 분포는 현재 실제 상품과 일치하고 매 렌더마다 수치나 목록이 바뀌지 않아야 합니다. 필터·카테고리·검색 연결과 기존 이미지 무결성, 상품 ID·가격·주문 호환을 확인합니다.
- 실제 PG·운영 DB·스키마·환경변수·키·게이트 변경은 수행하지 않습니다. 격리 PostgreSQL·합성 계정·합성 주문·별도 브라우저만 사용하며 완료 후 자체 자료를 정리합니다.
