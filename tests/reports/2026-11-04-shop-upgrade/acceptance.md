# 쇼핑몰 업그레이드 독립 QA 수용 조건

기준일: 2026-11-04. 실행 결과와 제품 SHA는 최종 보고서에 별도 기록합니다.

- 공개 쇼핑: 홈 → 실제 상품 목록 → 검색/카테고리/정렬 → 상세 → 옵션·수량 → 장바구니가 이어지고, 가짜 후기·구매량·할인 수치가 없어야 합니다.
- 구매후기: 로그인한 본인의 실제 결제완료·배송완료 상품만 작성합니다. 타인 주문·취소 주문·시연 주문·미배송 주문·중복·잘못된 별점·짧거나 긴 본문은 거절해야 합니다. 공개된 작성자명은 마스킹하고 본문은 텍스트로 표시해야 합니다.
- 배송: 현재 DB 역할이 ADMIN인 사용자만 PAID 일반 주문의 택배사·송장을 등록하고 배송완료를 기록합니다. 중복 요청은 중복 이력을 만들지 않고, 변경 전후의 배송 이력을 보존해야 합니다. 배송처리는 결제 상태와 금액을 바꾸면 안 됩니다.
- 소유권: 고객은 본인 주문·배송·거래내역만 볼 수 있고 관리자는 배송 대상 목록과 필요한 내역을 확인할 수 있어야 합니다.
- 배포 호환: 새 테이블 미적용 시 기존 상품·주문·결제 화면은 동작하고 후기·배송 쓰기는 준비 중으로 차단돼야 합니다. 연결/권한 오류를 빈 후기처럼 숨기면 안 됩니다.
- 반응형·접근성: 320/390/1280px와 200% 확대에서 본문 가로넘침·숨겨진 주요 명령이 없고, 44px 타깃·키보드 포커스·필드 라벨·실패 안내가 유지돼야 합니다.
- 안전 경계: 격리 PostgreSQL·합성 계정·합성 주문·별도 브라우저 context만 사용합니다. 실제 PG·LAONPAY·운영 DB·환경변수·키·기능 게이트를 변경하거나 호출하지 않습니다.
- 완료: 격리 서버·브라우저·DB·합성 세션을 정리하고 DEV 자체 검증과 독립 QA 결과를 구분합니다.
