## 실제로 검증한 동작

구매후기는 본인의 결제완료·배송완료 상품에만 허용했습니다. 타인 주문·취소·시연·결제대기·미배송·배송 중 상품, 잘못된 별점과 본문 길이는 거절했습니다. 같은 주문 항목의 동시 후기 요청은 1건만 저장했고 공개 집계·평균·작성자 마스킹·공개 DTO를 확인했습니다. 실제 브라우저의 후기 등록 Server Action을 호출하고, 같은 요청을 타인·비로그인 세션에서 재전송해 추가 저장이 없음을 확인했습니다. HTML 모양의 후기 내용은 텍스트로 표시되고 스크립트는 실행되지 않았습니다.

배송 관리는 관리자 여부를 현재 DB에서 재확인했습니다. 일반 사용자·권한이 강등된 관리자·취소·시연·결제대기 주문의 변경은 거절했습니다. 실제 송장 정정 Server Action과 배송완료 처리를 실행했고, 송장·정정 전후 이벤트·완료 이벤트·DB의 배송완료 상태가 일치했습니다. 동일 송장 및 동시 완료 요청은 중복 이력을 만들지 않았습니다. 배송완료 근거 메모는 서버에서도 필수입니다. 배송 처리 전후 주문의 결제 상태·금액·승인번호·거래번호는 바뀌지 않았습니다.

DB의 복합 FK는 다른 사용자나 다른 주문 항목에 후기를 결박하는 삽입을 차단했습니다. 별점/본문 CHECK, 배송완료 시각 NOT NULL 조건, 배송 이벤트 UPDATE/DELETE 방지 trigger를 실제로 검증했습니다. 신규 테이블이 없거나 감사 trigger가 비활성화되면 readiness가 닫히고, 후기 쓰기·배송 관리가 비활성화됐습니다. 실제 HTTP에서도 이 상태에서 기존 상품·주문 화면은 계속 열렸습니다.

고객의 주문·배송 내역은 본인 주문에만 표시됐습니다. 타인의 주문 내역과 관리자 화면에서는 개인 주문 정보가 노출되지 않았습니다. 인쇄 모드에서도 내역 문서의 제목이 남고 사이트 전역 머리말은 제외됐습니다.
